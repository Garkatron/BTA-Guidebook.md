# Formats
Use < & > chars to apply color
to text followed by a code:
* 0 = &0Black
* 1 = &1Dark Blue
* 2 = &2Dark Green
* 3 = &3Dark Aqua
* 4 = &4Dark Red
* 5 = &5Dark Purple
* 6 = &6Gold
* 7 = &7Gray
* 8 = &8Dark Gray
* 9 = &9Blue
* a = &aGreen
* b = &bAqua
* c = &cRed
* d = &dLight Purple
* e = &eYellow
* f = &fWhite
* s = &sShadow
* r = Reset
